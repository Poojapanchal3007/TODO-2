# Android To-Do App

Android coursework project with a Jetpack Compose interface, ViewModel support and Retrofit dependencies.

## Technologies

Kotlin · Android · Jetpack Compose · Material 3 · Gradle

## Run locally

1. Clone this repository.
2. Open the repository root in Android Studio.
3. Allow Gradle to sync and install any Android SDK components it requests.
4. Select an emulator or Android device and run the `app` configuration.
